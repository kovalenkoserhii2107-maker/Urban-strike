# План развития Stormhawk

## Этап 1. Вертолёт и ощущение полёта
- [x] Вертолёт игрока в стиле AH-1Z Viper: тандемная кабина с пилотами, сенсор на носу,
      подвижная трёхствольная пушка, крылья с блоками НУР и Hellfire, четырёхлопастные винты.
- [x] Hellfire видны на подвесках и исчезают при пуске.
- [x] Дым из двигателей при повреждениях.
- [x] Окраски в ангаре: морская пехота, джунгли, пустыня.

## Этап 2. Открытый мир, реалистичная графика, модули
- [x] Остров с рельефом и районами, трассы, трафик, аванпосты, события, карта с туманом войны.
- [x] PBR-графика, небо, вода, фасады, мягкие частицы, GTAO и bloom на высоком качестве.
- [x] 9 модулей с уровнями по главам, требования сюжетных заданий, модули видны на корпусе.
- [x] 5 сюжетных заданий в разных районах, окраски открываются по главам.

## Этап 3. Совместная игра по Wi-Fi (Co-op Multiplayer)
- [x] Сетевой модуль `NetworkManager` с поддержкой WebSocket и WebRTC DataChannels.
- [x] Автономный сервер `server.js` на чистом Node.js (автоопределение Wi-Fi IP, WebSocket Relay).
- [x] Модель и интерполяция вертолёта напарника (`RemotePlayer`) со световым маячком и шевроном.
- [x] Синхронизация стрельбы (пулемёт, НУР, Hellfire) и тепловых ловушек.
- [x] Таргетинг врагов на обоих игроков (выбор ближайшей цели и упреждение).
- [x] Столкновения вражеских снарядов и ПВО с обоими вертолётами.
- [x] Механика спасения и воскрешения напарника (эвакуация сбитого пилота лебёдкой на базу).
- [x] Экран совместной игры в меню (выбор роли Хост/Клиент, IP-подключение, обмен P2P-кодами).
- [x] Виджет напарника на HUD (броня, дистанция, пинг) и маркер на радаре.
- [x] Подключение по коду из 4 символов и ссылке-приглашению, автоматическое восстановление связи.

## Этап 4. Контент и глубина механик
- [ ] Ещё задания: сопровождение колонны, оборона базы, задания на время, катера.
- [ ] Новые враги: ПВО на крышах, ракетные катера, бронепоезд, снайперы.
- [ ] Выбор подвески перед вылетом: больше ракет или больше брони.
- [ ] Расширенная прокачка и новые вертолёты (транспортный Black Hawk, разведчик Kiowa).
- [ ] Погода (дождь, грозовой ветер, туман), засады врагов.

## Этап 5. Графика и скорость
- [ ] Объединение геометрии города (BatchedMesh) для FPS на слабых телефонах.
- [ ] Брызги воды, ночное освещение от взрывов.
- [ ] Тест на реальных устройствах и настройка качества графики.
