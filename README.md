# Stormhawk: Городской удар

Мобильный вертолётный боевик в духе 16-битной классики (изометрия, лебёдка, топливо/броня/боезапас),
сделанный с нуля на Three.js. Устанавливается на телефон как приложение (PWA) и работает офлайн.

## Возможности прототипа
- 3 миссии кампании: день, ночь (прожектор, светящиеся окна) и закат с боссом-крепостью.
- Живой мультяшный город: сотни деревьев, машин, фонарей, контейнеров, трафик, порт, маяк, вода с пеной.
- Разрушаемые здания (с тайниками), цепные взрывы машин и цистерн, обломки, дым, огонь, тени.
- Вертолёт: инерционная физика, автоприцел, пулемёт, ракеты Hydra, самонаводящиеся Hellfire,
  тепловые ловушки против ЗРК, лебёдка для людей и ящиков, дозаправка на базе.
- 12 типов противников: пехота, РПГ, джипы, танки, зенитки, ЗРК, радары, вертолёты, штаб, генераторы, босс с щитом.
- Комбо-очки, звёзды за миссию, ангар с улучшениями, сохранение прогресса.
- Синтезированные звук и музыка (без файлов), вибрация, геймпад и клавиатура.
- Экран установки приложения при входе, плавные переходы между экранами, кинематографичный взлёт.

## Запуск
```bash
npm install
npm run dev      # разработка, открыть адрес с телефона в той же сети
npm run build    # сборка в dist/
```

Управление на ПК: WASD — полёт, Пробел — пулемёт, Q/Shift — ракеты, E — Hellfire, F — ловушки, Esc — пауза.

## Публикация
Workflow `.github/workflows/deploy.yml` публикует `dist/` на GitHub Pages при пуше в `main`
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).
