# Stormhawk: Городской удар

Мобильный вертолётный боевик в духе 16-битной классики (изометрия, лебёдка, топливо/броня/боезапас),
сделанный с нуля на Three.js. Устанавливается на телефон как приложение (PWA) и работает офлайн.

## Возможности
- **Открытый мир**: остров ~1,6×1,6 км с рельефом и горами, город Порт-Лазурь, промзона,
  авиабаза врага, три деревни, леса, пляжи, трассы между районами, живой трафик.
- **Реалистичная графика**: PBR-материалы, освещение от неба, фасады с отражающими окнами
  и ночной подсветкой, вода с френелем, бликами и прибоем, мягкий дым и огонь, тени,
  объёмное затенение (GTAO) и bloom на высоком качестве. Смена времени суток.
- **Сюжет из 5 заданий** в разных районах: у каждого свои требования к модулям вертолёта.
- **Модули и кастомизация**: 9 модулей (броня, двигатели, топливо, пушка, НУР, Hellfire,
  РЭБ, сенсоры, лебёдка), уровни открываются по главам и видны на корпусе; 5 окрасок.
- **Аванпосты**: 8 вражеских лагерей; после зачистки становятся нашими точками дозаправки
  и возрождения. Случайные события: сбитые пилоты, конвои, сбросы снабжения.
- **Карта** с туманом войны, маркерами и путевой точкой (кнопка 🗺 или клавиша M).
- Вертолёт в стиле AH-1Z Viper: подвижная пушка, ракеты на подвесках, дым при повреждениях.
- PWA: экран установки при входе, работа офлайн, сохранение прогресса.

## Запуск
```bash
npm install
npm run dev      # разработка, открыть адрес с телефона в той же сети
npm run build    # сборка в dist/
```

Управление на ПК: WASD — полёт, Пробел — пулемёт, Q/Shift — ракеты, E — Hellfire, F — ловушки, M — карта, Esc — пауза.

## Публикация
Workflow `.github/workflows/deploy.yml` публикует `dist/` на GitHub Pages при пуше в `main`
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).
