# Stormhawk: Городской удар

Мобильный вертолётный боевик в духе 16-битной классики (изометрия, лебёдка, топливо/броня/боезапас),
сделанный с нуля на Three.js. Устанавливается на телефон как приложение (PWA), работает офлайн и поддерживает **совместную игру вдвоём по короткому коду**.

## Возможности
- **Совместная игра вдвоём (Co-op)**:
  - Ведущий нажимает «Создать игру» и получает код из 4 символов; напарник вводит код или открывает ссылку-приглашение.
  - Соединение прямое между телефонами (WebRTC); без интернета — через `npm run coop` в локальной сети.
  - Связь восстанавливается сама при кратком обрыве (до 30 с); если напарник вышел, игра продолжается в одиночку.
  - Синхронизация вертолётов, стрельбы, ловушек, лебёдки и состояния врагов (ведущий решает, кто из врагов жив).
  - Враги выбирают целью ближайшего или атакующего игрока.
  - **Спасение напарника**: сбитый пилот появляется на карте у второго игрока — его можно поднять лебёдкой и доставить на базу.
  - HUD-радар и статус напарника: дистанция, броня, пинг.
- **Масштабный открытый мир**: остров расширен до ~2,4×2,4 км (мир 2,8×2,8 км) с разнообразными биомами и районами:
  - **Порт-Лазурь**: мегаполис с небоскрёбами, парками и набережной;
  - **Промзона «Северсталь»**: заводы с трубами, склады и краны;
  - **Авиабаза Кроста**: взлётно-посадочные полосы, ангары, истребители и радары;
  - **Бухта Нефтяников**: морской порт, нефтеналивные резервуары, факельные вышки и танкеры;
  - **РЛС «Купол»**: высокогорный комплекс с тремя радиопрозрачными куполами и мачтами связи;
  - **Дамба Чёрного Ущелья**: массивная бетонная плотина с гидроэлектростанцией и горным каньоном;
  - **Курорт «Золотые Пески»**: лазурные лагуны, отель, белые виллы с бассейнами и яхтами;
  - **Бункер «Объект-42»**: секретный подземный комплекс в скалах на высоте 80 м;
  - **5 деревень**: Озёрное, Развилка, Верхний Брод, Сосновый Бор и Рыбачья Заводь;
  - **14 аванпостов**: опорные пункты с заправкой FARP и ремонтом после зачистки;
  - Разветвлённая сеть скоростных трасс с живым автомобильным трафиком.
- **Реалистичная графика**: PBR-материалы, освещение от неба, фасады с отражающими окнами
  и ночной подсветкой, вода с френелем, бликами и прибоем, мягкий дым и огонь, тени,
  объёмное затенение (GTAO) и bloom на высоком качестве. Смена времени суток.
- **Сюжет из 5 заданий** в разных районах: у каждого свои требования к модулям вертолёта.
- **Модули и кастомизация**: 9 модулей (броня, двигатели, топливо, пушка, НУР, Hellfire,
  РЭБ, сенсоры, лебёдка), уровни открываются по главам и видны на корпусе; 5 окрасок.
- **Аванпосты**: 8 вражеских лагерей; после зачистки становятся нашими точками дозаправки
  и возрождения. Случайные события: сбитые пилоты, конвои, сбросы снабжения.
- **Карта** с туманом войны, маркерами и путевой точкой (кнопка 🗺 или клавиша M).
- Вертолёт в стиле AH-1Z Viper: подвижная пушка, ракеты на подвесках, дым при повреждениях.
- PWA: экран установки при входе, работа офлайн, сохранение прогресса.

## Запуск одиночной игры
```bash
npm install
npm run dev      # запуск Vite для локальной разработки
npm run build    # сборка в dist/
```

## Совместная игра

### Обычный способ (нужен интернет на обоих телефонах)
1. Оба открывают игру (например, опубликованную на GitHub Pages).
2. Ведущий: **«👥 Совместно» → «Создать игру»** — появится код из 4 символов и кнопка **«Отправить приглашение»**.
3. Напарник вводит код (подключение начнётся само после четвёртого символа) или просто открывает присланную ссылку.
4. Ведущий нажимает **«Взлёт вдвоём»** — вылет начнётся у обоих.

Интернет нужен только чтобы «познакомить» телефоны через бесплатный сервер PeerJS; сама игра идёт напрямую
между устройствами. Надёжнее всего — когда оба в одной сети Wi-Fi: в мобильных сетях некоторые операторы
не пропускают прямое соединение.

### Без интернета (локальная сеть)
```bash
npm install
npm run coop     # собирает игру и запускает сервер
```
Сервер напечатает адрес вида `http://192.168.1.45:8080` — откройте его на обоих телефонах в одной сети Wi-Fi.
Дальше всё так же: «Создать игру» → код → «Взлёт вдвоём». Игра сама поймёт, что открыта с этого сервера, и пойдёт через него.

## Управление на ПК
WASD — полёт, Пробел — пулемёт, Q / Shift — ракеты Hydra, E — ракеты Hellfire, F — ловушки, M — карта, Esc — пауза.
На смартфонах управление осуществляется виртуальным джойстиком и сенсорными кнопками.

## Публикация
Workflow `.github/workflows/deploy.yml` публикует `dist/` на GitHub Pages при пуше в `main`
(в настройках репозитория: Settings → Pages → Source: GitHub Actions).
