# Stormhawk: Городской удар

Мобильный вертолётный боевик в духе 16-битной классики (изометрия, лебёдка, топливо/броня/боезапас),
сделанный с нуля на Three.js. Устанавливается на телефон как приложение (PWA), работает офлайн и поддерживает **совместную игру по локальной сети Wi-Fi**.

## Возможности
- **Совместная игра по Wi-Fi (Co-op Multiplayer)**:
  - Вылет вдвоём на одном острове: ведущий (Host) и ведомый (Client).
  - Два сетевых транспорта: встроенный легковесный сервер WebSocket или прямое соединение WebRTC P2P (браузер-к-браузеру без сервера).
  - Синхронизация физики вертолётов, стрельбы, ловушек, лебёдки и состояния врагов.
  - Умный AI врагов: техника и ПВО динамически выбирают целью ближайшего или атакующего игрока.
  - **Механика спасения напарника (Revive)**: сбитый пилот катапультируется с парашютом. Второй игрок может поднять его лебёдкой и доставить на базу для возвращения вертолёта в строй!
  - HUD-радар и статус напарника с отображением дистанции, прочности брони и сетевого пинга.
- **Открытый мир**: остров ~1,6×1,6 км с рельефом и горами, город Порт-Лазурь, промзона,
  авиабаза врага, три деревни, леса, пляжи, трассы между районами, живой трафик.
- **Реалистичная графика**: PBR-материалы, освещение от неба, фасады с отражающими окнами
  и ночной подсветкой, вода с френелем, бликами и прибоем, мягкий дым и огонь, тени,
  объёмное затенение (GTAO) и bloom на высоком качестве. Смена времени суток.
- **Сюжет из 5 заданий** в разных районах: у каждого свои требования к модулям вертолёта.
- **Модули и кастомизация**: 9 модулей (броня, двигатели, топливо, пушка, НУР, Hellfire,
  РЭБ, сенсоры, лебёдка), уровни открываются по главам и видны на корпусе; 5 окрасок.
- **Аванпосты**: 8 вражеских лагерей; после зачистки становятся нашими точками дозаправки
  и возрождения. Случайные события: сбитые пилоты, конвои, сбросы снабжения.
- **Карта** с туманом войны, маркерами и путевой точкой (кнопка 🗺 или клавиша M).
- Вертолёт в стиле AH-1Z Viper: подвижная пушка, ракеты на подвесках, дым при повреждениях.
- PWA: экран установки при входе, работа офлайн, сохранение прогресса.

## Запуск одиночной игры
```bash
npm install
npm run dev      # запуск Vite для локальной разработки
npm run build    # сборка в dist/
```

## Запуск совместной игры по Wi-Fi (Co-op)

### Вариант 1: Локальный сервер по Wi-Fi (рекомендуемый)
1. Убедитесь, что оба устройства (телефоны/ПК) подключены к одной сети Wi-Fi (или один телефон раздаёт точку доступа Wi-Fi Hotspot).
2. На компьютере или хосте запустите сервер:
   ```bash
   npm run coop
   # или: node server.js
   ```
   В консоли отобразится ваш локальный IP (например: `http://192.168.1.45:8080`).
3. Откройте эту ссылку в браузере на обоих устройствах.
4. В главном меню нажмите кнопку **«👥 Совместно (Wi-Fi)»**:
   - Первый игрок нажимает **«Создать лобби (Хост)»**.
   - Второй игрок вводит IP хоста (или оставляет по умолчанию) и нажимает **«Подключиться к Хосту»**.
5. Нажмите **«Взлёт вдвоём 🚁🚁»**!

### Вариант 2: Прямое P2P соединение WebRTC (без сервера)
1. В меню **«👥 Совместно (Wi-Fi)»** перейдите на вкладку **«Прямое P2P (WebRTC)»**.
2. Хост нажимает **«Создать код комнаты»** и копирует сгенерированный код.
3. Клиент вставляет код, нажимает **«Вставить код и ответить»** и отправляет ответный код Хосту.
4. Хост нажимает **«Применить код»** — защищённый прямой канал связи открыт!

## Управление на ПК
WASD — полёт, Пробел — пулемёт, Q / Shift — ракеты Hydra, E — ракеты Hellfire, F — ловушки, M — карта, Esc — пауза.
На смартфонах управление осуществляется виртуальным джойстиком и сенсорными кнопками.
